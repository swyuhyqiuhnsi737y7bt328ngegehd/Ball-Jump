# Ball Jump · 弹球闯关

一个「平台跳跃 + 关卡编辑器」的小游戏，仓库里有两个版本：

| 目录 | 说明 |
|---|---|
| [`original/`](original/) | **原版**：单文件网页游戏 `cd.html`。HTML + Canvas + 原生 JS，零依赖，双击浏览器即玩 |
| [`godot/`](godot/) | **Godot 4 移植版**：完整重写为 GDScript，含关卡编辑器、本地存档、JSON 互通 |

---

## 玩法

控制一颗金色小球，左右移动、二段跳，躲开尖刺吃金币，碰到发光的终点圈过关。

| 操作 | 按键 |
|---|---|
| 左右移动 | `←` `→` 或 `A` `D` |
| 跳跃 / 二段跳 | `空格` / `↑` / `W`（松开可截断跳跃高度） |
| 变速（TAS） | `[` `]` 在 0.1x ~ 3x 间切换，`\` 重置 |
| 冻结 / 逐帧 | `P` 冻结，冻结时 `F` 单步 |
| 复盘回放 | 死亡后自动弹出；通关浮层上有「复盘刚才这一局」；也可以随时按 `R` 手动回放 |
| 菜单 / 返回 | `Esc` |

### 关卡元素

| 元素 | 说明 |
|---|---|
| 平台 | 实心方块，四周都能站，顶部有一道高光 |
| 尖刺 | 四个朝向（↑↓←→） |
| 弹簧 | 踩上去弹到 1180 的初速（约 316px 高） |
| 加速带 | 把水平速度推到设定值，方向可左右，是两端圆角的胶囊 |
| 金币 | 吃满计数，通关界面显示 `x/y` |
| 传送门 | 两两配对（1A↔1B、2A↔2B…），进去从配对的另一个出来 |
| 存档点 | 碰到后死亡从存档点复活 |
| 起点 / 终点 | 出生位置、过关位置 |

### 复盘（死亡回放）

球每物理帧记一次状态（环形缓冲，最近 30 秒）。**死亡时自动弹面板；通关时浮层上也有「复盘刚才这一局」**：

- 进度条任意拖动回看
- `重播` / `暂停`，倍速 `0.25× 0.5× 1× 2×`
- 播到结尾自动补一次死亡粒子特效并暂停
- `Esc` 或「关闭」：死亡复盘回出生点继续玩，通关复盘回通关浮层接着点「下一关」
- 没死也可以按 `R` 手动回放刚才这一段

### 导出视频

复盘面板上的「导出视频」把这段回放编码成 **MJPEG 的 .avi**（30fps / 900×560），
默认存到系统「视频」文件夹并自动打开所在位置。Godot 没有内置视频编码，
容器是自己写的（`godot/scripts/avi_writer.gd`），出来的文件 VLC / ffmpeg / 剪映都能直接打开。

### 关卡编辑器

菜单里「＋ 新建关卡」或某一关的「编辑」：

- **工具**：移动 / 平台 / 尖刺 / 弹簧 / 加速带 / 金币 / 传送门 / 存档点 / 起点 / 终点 / 橡皮
- **画**：选好工具在画布上拖拽出矩形；金币、传送门、存档点点一下即可
- **改**：用「移动」点选后，右侧属性面板改坐标 / 宽高 / 半径 / 力度 / 朝向，也可以直接拖动搬家
- **删**：橡皮工具，或直接在物件上点右键
- **吸附**：默认 10px 网格吸附，可关
- **试玩**：`▶ 试玩` 直接跑一遍当前编辑内容（不写入关卡列表），通关或按 `Esc` 回到编辑器
- **JSON**：当前关卡的 JSON 导入 / 导出，网页版和 Godot 版格式完全一致，可以互相搬运

## 运行

### 原版（网页）

直接双击 `original/cd.html`。关卡存在浏览器 `localStorage`，也可以用「导出全部 / 导入全部」在文件层面备份。

### Godot 版

需要 **Godot 4**（开发时用的是 4.7）：

```bash
godot --path godot            # 或者用编辑器打开 godot/ 目录后按 F5
```

第一次启动会自动生成一张示例关卡。关卡存在 `user://balljump_levels.json`。

调试用启动参数：`--play` 直接进第一关、`--play --level=N` 进第 N 关、`--edit-level` 直接进编辑器。

## 两个版本的关系

- **关卡 JSON 完全互通**：字段名、取值范围、默认值、坐标钳制都一致。网页版「导出全部」出来的
  `balljump-levels.json`，在 Godot 版菜单里「导入全部」直接能用，反过来也行。
- **物理参数逐字节对齐**：重力 2200、最大移速 340、跳跃 820/760、终端速度 1050、
  土狼时间 0.10s、跳跃缓冲 0.12s、固定步长 1/120，主循环也是同一套「累加器 + 变速 + 冻结/逐帧」结构，
  所以两个版本手感一致。
- **视觉按同一套语言实现**：原版靠 Canvas 的 `roundRectPath` / `createLinearGradient` /
  `createRadialGradient` / `shadowBlur`，Godot 版对应实现为圆角多边形、
  逐顶点着色渐变、CPU 烘的径向渐变贴图、以及叠层扩散的光晕。详见
  [`godot/README.md`](godot/README.md) 里的对照表。

## 自检

Godot 版带两套无头自检：

```bash
godot --headless --path godot --script res://tests/physics_test.gd   # 物理 22 项
godot --headless --path godot --script res://tests/editor_test.gd    # 编辑器 10 项
```

物理：自由落体与终端速度、落地、跳跃高度（离散积分 156.25px）、尖刺致死、金币、
传送门、弹簧、终点判定、关卡 JSON 往返与越界钳制。

编辑器：新建关卡、拖拽画平台、点放金币、移动工具拖物件、右键擦除，
以及「在工具栏 / 属性面板上拖拽不会误画到关卡里」「自检不写玩家存档」。
